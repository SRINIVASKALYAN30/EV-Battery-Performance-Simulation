
PROJECT TITLE:
Simulation and Analysis of Electric Vehicle
Battery Performance Using Python

PROJECT DESCRIPTION:
This project simulates the performance of
electric vehicle batteries using Python.

SIMULATIONS:
1. Battery Charging and Discharging
2. Battery Capacity Comparison
3. Slow Charging vs Fast Charging
4. Driving Speed vs Battery Consumption

TECHNOLOGIES:
- Python
- NumPy
- Matplotlib

OUTPUTS:
- Battery SOC calculations
- Charging and discharging graphs
- Battery capacity comparison
- Charging time comparison
- Driving range analysis

PROJECT TYPE:
Software-Based Simulation
